# Stock Management Application (CCS)

Stock Management is a professional desktop application built with **Java, Python, and SQL** designed specifically for managing spare parts inventory, automating local and international quotations, and ensuring strict data integrity. 

This project bridges data engineering with an interactive user interface to optimize traditional administrative workflows, replacing manual entries with automated processes.

## 🚀 Key Features

* **Excel File Integration:** Automatically imports massive stock lists, pricing structures, and minimum stock alerts from raw Excel spreadsheets, parsing and validating data before system injection.
* **Automated PDF Generation:** Converts analytical data and customer quotes into clean, standardized, client-ready PDF documents instantly.
* **Multi-Currency & Regional Quotations:** Logic structured to generate specific financial metrics for both local and international clients (handling distinct pricing tiers and costs).
* **Comprehensive Transaction History:** Maintains a structured SQL database history of all actions, enabling detailed tracking, debugging, and operational audits.

---

## 🛠️ Tech Stack & Environment

* **Languages:** Java (Swing UI Framework), Python (Data Parsing Modules), SQL (Database Engine).
* **Libraries & Layouts:** MigLayout, JGoodies Forms for responsive and structured desktop interfaces.
* **Environment:** Developed and tested natively leveraging Linux environments via WSL2 (Ubuntu).
* **Data Standards:** Mapped specifically to handle industrial inventory data structures (P/N, Part Numbers, Descriptions, and Minimum Thresholds).
